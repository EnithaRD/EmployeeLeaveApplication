# Vibe Coding Rules

## 1. Understand before changing
I should investigate the codebase before asking Claude to modify it.

## 2. Verify Claude's claims
A confident answer can still be wrong, so I should check important claims against the actual code.

## 3. Read permission requests
I should understand what Claude wants to run or change before approving it.

## 4. Give Claude the right context
I should use `@` when I already know which file matters and let Claude search when I don't.

## 5. Keep boundaries clear
I should explicitly tell Claude what it may change and what it must leave alone.
